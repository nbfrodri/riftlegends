## Cómo trabajar

- **Subagentes y Codex:** el usuario elige modelo y effort antes de lanzarlos. Reparto del 21-11: Codex **astra high** para lo visual y **sol medium** para el resto; el usuario pide delegar en Codex todo lo posible. Subagentes de Claude: Sonnet medium (Opus medium para lo visual si Codex no está), como mucho dos a la vez. Revisa siempre su trabajo: el #172 traía un fallo de atribución de kills y los PR en paralelo chocan al fusionar.
- **Reglas de UI del usuario:** iconos y nunca glifos de texto; nada de «Δ» ni números con signo (decirlo en palabras); campeones no disponibles en gris con raya diagonal, sin etiquetas; desplegables con estilo Caja; tablas alineadas.
- **Capturas visuales:** solo se regeneran en el CI con el workflow «Visual baselines»; se revisan a mano y se commitean.
- **Codex:** antes de delegar, el usuario elige el modelo y el effort; se le ofrece una recomendación. Usa la skill `cross-delegate`, con un worktree por tarea y un registro en `docs/handoffs/` mientras dure. Si el último mensaje de Codex es la respuesta a un hook, el informe real está en sus eventos.
- **Semillas:** siempre con `deriveSeed`. Con semillas pequeñas y seguidas, la primera tirada de xoroshiro sale sesgada.
- **pnpm:** respeta la antigüedad mínima de las versiones; no se añaden excepciones.
- **Comprobaciones:** `mise exec -- pnpm verify` (Biome, tipos, tests y Knip) y `mise exec -- pnpm e2e`.
