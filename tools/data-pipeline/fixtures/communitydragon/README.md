# Fixtures de CommunityDragon

Recortes **sintéticos** de `characters/<id>/<id>.bin.json` y de `lol.stringtable.json` (parche 16.23) para seis campeones: Galio, Thresh, Malphite, Yasuo, Soraka y Jinx. Conservan la estructura, las etiquetas de habilidad (`mSpellTags`), los enfriamientos y el alcance de ataque. Los tooltips están reescritos: solo mantienen las marcas (`<status>`, `<magicDamage>`, `<healing>`...) con texto de relleno, para no copiar el texto de Riot.
